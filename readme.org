* Введение

`boardgame.org` — это текстовая настольная среда для Emacs, в которой документы формата Org-mode служат понятным человеку, редактируемым и версионируемым представлением игровых объектов, сукна и состояния игрового мира.

Проект разработан в строгом соответствии с архитектурной спецификацией из [[file:boardgame-org.md][boardgame-org.md]].

* Главные архитектурные принципы

** 1. Объект — это файл (Section 2)
Каждый самостоятельно существующий объект игрового мира (карта, кость d6/d20, фишка, пешка, сундук) представлен отдельным файлом Org (`objects/<id>.org`).

#+BEGIN_QUOTE
*Фундаментальный инвариант:* Независимый игровой объект имеет свой собственный Org-документ. Если объект поглощается другой формой представления (например, стопкой), его прежний отдельный файл удаляется с диска.
#+END_QUOTE

** 2. Стопки и Постоянные Контейнеры принципиально различны (Section 3)

| Свойство | Стопка (Stack) | Постоянный контейнер (Container) |
|---|---|---|
| *Основная цель* | Консолидация Org-документов в один | Организация без слияния файлов |
| *Файлы объектов* | Поглощаются в документ стопки; отдельные файлы удаляются | Сохраняются независимо на диске |
| *Представление* | Вложенные подзаголовки с Org-свойствами | Список ссылок `[[file:objects/...][...]]` |
| *Расформирование* | Воссоздает отдельные файлы и удаляет файл стопки | Не требуется |
| *Пустое состояние* | Перестает существовать при расформировании | Персистентен даже пустым (колода, мешок) |
| *Операции* | Слияние, расформирование | Перемешивание, взятие верхней/произвольной карты |

** 3. Нормализация размеров сукна (Felt Normalization, Section 4.6)
При загрузке и рендеринге блока =#+begin_src felt=:
- Недостающие клетки строки автоматически заполняются символом сукна по умолчанию (например, =.=).
- Символы, выходящие за пределы заявленных =:WIDTH:= и =:HEIGHT:=, игнорируются.

** 4. Отображение перекрывающихся объектов (Section 5)
Когда несколько объектов занимают одну и ту же клетку стола:
- Верхний объект отображается своим глифом (например, ~🂡~, ~🎲~, ~🪙~).
- Непосредственно слева от него отображается числовой индикатор количества: от ~1~ до ~9~; при количестве больше 9 отображается знак ~+~.

** 5. Версионирование и восстановление через Git (Section 6)
Все изменения фиксируются в Git-репозитории мира с понятными сообщениями коммитов, что позволяет легко откатиться к любому состоянию партии.

* Установка и запуск в Emacs
Пакет расположен в каталоге =src.el/=.
** Вариант 1: Через Straight / use-package
#+begin_src emacs-lisp
(use-package boardgame-org
  :straight (:host github :repo "Buyn/boardgame-org" :files ("src.el/*.el"))
  :bind (("<f6>" . boardgame-org-menu))
  :config
  (setq boardgame-org-world-directory "~/Dev/boardgame-world/"))
#+end_src

** Вариант 2: Локальная загрузка
Поместите файлы пакета в ваш =load-path=:
#+begin_src emacs-lisp
(add-to-list 'load-path "~/Dev/emacs/boardgame-org/src.el/")
(require 'boardgame-org)

;; Запуск настольной среды:
(setq boardgame-org-world-directory "~/Dev/emacs/boardgame-world/")
(boardgame-org "~/Dev/emacs/boardgame-world/")
#+end_src

* Горячие клавиши и управление

В буфере =*boardgame-org*=:

| Клавиша | Функция | Описание |
|---|---|---|
| ~← ↓ ↑ →~ / ~h j k l~ / ~C-f C-b C-n C-p~ | Перемещение курсора | Передвижение по клеткам сукна (A1, B3 и т.д.) |
| ~?~ или ~SPC~ | =boardgame-org-menu= | Интерактивное меню действий |
| ~m~ | =boardgame-org-move-at-point= | Переместить объект на указанные координаты |
| ~H~ | =boardgame-org-pickup-to-hand= | Взять верхний объект в руку игрока |
| ~P~ | =boardgame-org-play-from-hand= | Сыграть объект из руки на текущую клетку |
| ~S~ | =boardgame-org-consolidate-stack-at-point= | Объединить объекты клетки в единый Org-документ стопки (удаляет отдельные файлы) |
| ~U~ | =boardgame-org-expand-stack-at-point= | Разобрать стопку обратно в отдельные файлы |
| ~d~ | =boardgame-org-draw-from-container-at-point= | Взять верхнюю карту из контейнера (колоды) в руку |
| ~s~ | =boardgame-org-shuffle-container-at-point= | Перемешать контейнер (колоду) |
| ~r~ | =boardgame-org-roll-die-at-point= | Бросить кость (d6, d20) |
| ~F~ | =boardgame-org-flip-card-at-point= | Перевернуть карту (рубашкой вверх/вниз) |
| ~o~ | =boardgame-org-open-org-at-point= | Открыть исходный Org-документ объекта в соседнем окне |
| ~g~ | =boardgame-org-commit-action= | Сделать коммит текущего состояния в Git |
| ~q~ | =quit-window= | Закрыть буфер стола |

* Модульная структура пакета (каталог src.el/)

1. =src.el/boardgame-org-core.el= — базовые структуры (`cl-defstruct`), переменные конфигурации и интеграция с Git.
2. =src.el/boardgame-org-object.el= — парсинг, сериализация и управление жизненным циклом файлов объектов.
3. =src.el/boardgame-org-stack.el= — консолидация документов в стопку и обратное расформирование.
4. =src.el/boardgame-org-container.el= — постоянные контейнеры (колоды, сундуки) со списками ссылок.
5. =src.el/boardgame-org-hand.el= — документы рук игроков (`hands/<player>.org`).
6. =src.el/boardgame-org-board.el= — модель игрового поля, нормализация сукна и таблица размещения.
7. =src.el/boardgame-org-render.el= — отрисовка буфера, отображение стопок и числовых индикаторов.
8. =src.el/boardgame-org.el= — главный мажорный режим, клавиатурные привязки и интерактивные команды.
9. =src.el/boardgame-org-test.el= — набор регрессионных тестов ERT (Emacs Lisp Regression Testing).

* Тестирование (ERT)

Для запуска тестов в Emacs:
#+begin_src emacs-lisp
(load-file "src.el/boardgame-org-test.el")
(ert "^boardgame-org")
#+end_src


Тесты верифицируют:
- Корректную нормализацию размеров сукна при любых входных данных.
- Сохранение инварианта: создание независимых файлов при создании объектов и удаление при удалении.
- Удаление отдельных файлов при создании стопки и их воссоздание при разборе.
- Сохранение файлов объектов при операциях с контейнерами (взятие карт, перемешивание).
